# Superstore Retail Data Analysis (SQL Project)

This is a personal data analysis project where I analyzed a retail sales dataset (`retail_db`) using MySQL Workbench. The main goal was to explore the sales data, practice SQL queries, and extract business insights about products, regions, and customer behavior.

---

## Tools Used
* **Database:** MySQL Server
* **Tool:** MySQL Workbench
* **Language:** SQL

---

## Dataset Overview
The project uses the `train` dataset inside the `retail_db` database. Key columns include:
* `Order ID` - Unique ID for orders
* `Customer Name` - Customer identity
* `Category` & `Sub-Category` - Product classification
* `Region` & `State` - Geographic details
* `Sales` - Total revenue per order
